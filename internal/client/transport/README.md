# Транспорт gRPC (`internal/client/transport`)

Пакет поднимает соединение к серверу: **TLS с кастомным CA** или незащищённый режим (`insecure`), плюс unary-interceptor для подстановки **access JWT** в метаданные запросов.

Реализация предназначена как референс для собственных клиентов; поведение и флаги CLI см. в корневом [`internal/client/README.md`](../README.md).
